# Корни

Агент-исследователь семьи: расспрос → поиск по открытым источникам → древо.
План — [docs/plan.md](docs/plan.md).

## Правила

- Не выдумывать имена, даты, места и связи. Неизвестное остаётся неизвестным.
- У каждого факта есть происхождение: «со слов», «документ» (со ссылкой на оригинал) или «гипотеза».
- Агент пишет в древо сразу, но любое изменение можно отменить. Отдельной цепочки проверки нет.
- Никогда не сообщать, что поиск выполнен или что-то найдено, если источник реально не опрашивался.
- Капчи и логины на внешних сайтах не обходить: агент останавливается и просит человека.
- Ключи, `.env`, данные семей и скриншоты с личными данными не попадают в Git.
- Для тестов и демо — только синтетические люди.
- Дизайн: спокойный, лаконичный, Apple/Notion/Vercel. Удобно на телефоне.

## Проверка

`npm run build` — типы и сборка фронтенда.
