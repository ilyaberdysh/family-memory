# План

## Продукт

Три вкладки:

1. **Агент** — точка входа. Короткий расспрос (фамилии по обеим линиям, старшие
   предки, места, годы, события, сословие), затем поиск по источникам. Находки
   приходят в чат и в панель «Находки»: фрагмент скана, распознанный текст, ссылка.
2. **Древо** — собирается из рассказа и находок. Сплошная линия — документ или
   «со слов», пунктир — гипотеза. Ручное редактирование.
3. **Альбом** — фото, аудио, письма. Не входит в MVP.

## Источники

| Источник | Способ |
| --- | --- |
| Яндекс Поиск по архивам | браузерный адаптер (Playwright) |
| Familio | браузерный адаптер |
| FamilySearch | API / MCP-сервер, нужен ключ разработчика |
| ГИС УИАД | агент находит дело и шифр, заказ — человек через Госуслуги |
| Память народа, ОБД «Мемориал», Подвиг народа | браузерный адаптер |
| Wikidata, Internet Archive, Europeana | API |

Перед подключением каждого — проверить правила сайта. Капчи и логины не обходим.

## Архитектура

Чат → `/api/chat` → агент (AI SDK 7, при росте — Mastra) с инструментами:
`update_tree` (пишет сразу, с происхождением) и `start_research` (фоновая задача).
Фоновые задачи гоняют адаптеры источников и стримят прогресс обратно в чат.

## Этапы

1. ✅ Дизайн и каркас: три вкладки, живой чат с моделью, пустые древо и альбом.
2. Расспрос → древо: агент извлекает людей и связи из разговора, древо рисуется.
3. Первые источники: Яндекс Архивы и FamilySearch, карточки находок.
4. Остальные источники, доводка.
5. Альбом.
