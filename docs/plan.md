# План

## Продукт

Три вкладки:

1. **Агент** — точка входа. Короткий расспрос (фамилии по обеим линиям, старшие
   предки, места, годы, события, сословие), затем поиск по источникам. Находки
   приходят в чат и в панель «Находки»: фрагмент скана, распознанный текст, ссылка.
2. **Древо** — собирается из рассказа и находок. Сплошная линия — документ или
   «со слов», пунктир — гипотеза. Ручное редактирование.
3. **Альбом** — фото, аудио, письма. Не входит в MVP.

| Яндекс Поиск по архивам | браузерный адаптер; на 13.10.2026 сервис на паузе |

| Wikidata, Internet Archive, Europeana | API |

Перед подключением каждого — проверить правила сайта. Капчи и логины не обходим.

## Архитектура

Чат → `/api/chat` → агент (AI SDK 7, при росте — Mastra) с инструментами:
`update_tree` (пишет сразу, с происхождением) и `start_research` (фоновая задача).
Фоновые задачи гоняют адаптеры источников и стримят прогресс обратно в чат.

## Этапы

1. ✅ Дизайн и каркас: три вкладки, живой чат с моделью, пустые древо и альбом.
2. ✅ Расспрос → древо: агент сам заносит людей и связи (add_person, update_person, link_people, remove_person), гипотезы из отчеств — пунктиром, отмена любого шага.
3. ✅ Первые источники: ОБД «Мемориал» — агент сам ищет (`search_obd_memorial`) и читает карточки
   (`read_obd_record`) в обычном Chromium через Playwright, без обходов защиты; «Память народа» и
   FamilySearch — готовые ссылки (`prepare_search_links`). Яндекс Поиск по архивам на 13.10.2026
   временно недоступен (сервис на паузе).
4. Остальные источники, доводка.
5. Альбом.

## Бэклог

- **Список разговоров.** «Новый разговор» сейчас стирает предыдущий: история лежит одна, в
  localStorage браузера. Нужно хранить разговоры на сервере, показывать их списком (боковая
  панель или меню в шапке) и возвращаться к любому. Заодно появятся серверные логи диалогов для
  разбора ошибок агента.
- Сохранять находки (записи из поиска) отдельно от чата, чтобы они не терялись вместе с разговором.
- Ручное редактирование полей человека в древе.
- Familio и ГИС УИАД; Яндекс Поиск по архивам — когда сервис вернётся.
- Голосовой ввод в чате.
